# Право Силы

2D action-RPG с видом сверху: бой в реальном времени, большой мир и рост персонажа.
Прототип на чистом JavaScript, без сборки. Пиксель-арт, разрешение 320×240, прицел на портативную консоль.

Играть: открыть страницу проекта (GitHub Pages) или запустить локально:

```bash
python3 -m http.server 8791
```

и открыть `http://localhost:8791`.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Движение |
| Space | Взаимодействие, «далее». Удерживать — обыскать, стащить, разделать |
| Shift | Рывок |
| J | Удар ножом |
| K | Метательный нож |
| E | Быстрая кнопка (предмет назначается в вещах) |
| Enter | Вещи и характеристики |
| Q | В меню — выход в главное меню |

Геймпад тоже поддерживается.

## Что готово

- **Глава 0 «Трущобы»** — кривые проулки, жители со своими характерами, хлам и кражи, квесты на хлеб,
  нож и лекарство, погоня, скрытность в сумерках и бегство из города.
- **Глава 1 «Чёрный лес»** — ночёвка у костра, охота, звери силы, охотник-пользователь, заброшенная хижина.
- **Глава 2 «Дорога в город»** — гринд-глава: 10 локаций, испытание у извозчика, гильдия с рангами
  от G- до E+, больше двадцати заказов, хутор, оружие, доспехи и метательные ножи.

## Деплой на GitHub Pages

Workflow `.github/workflows/pages.yml` уже настроен: он публикует содержимое репозитория при каждом пуше
в `main` и по кнопке Run workflow.

Чтобы он заработал, нужно один раз включить Pages: **Settings → Pages → Source: GitHub Actions**.

Важно: для **приватных** репозиториев Pages доступен только на платных планах (Pro/Team/Enterprise).
На бесплатном плане есть два пути: сделать репозиторий публичным или поднять план. До этого запуски
workflow будут падать на шаге деплоя — это ожидаемо.
